# MusicTag link policy

MusicTag uses one public portfolio address: `https://katherine0292.github.io/MusicTag/`.

The repository is published from `main` at its root directory. The README contains only this portfolio hyperlink. Feature explanations, research, scope and evaluation status are written directly in the README instead of sending readers to other pages or files.

Images and recordings are local repository assets. The portfolio keeps its screen gallery, hardware interaction and complete phone recording on the page. It has no outgoing content buttons.

The local link audit checks asset destinations and filename case. `.nojekyll` remains present so static assets are published without Jekyll transformation.

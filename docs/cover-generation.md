# Retained original cover and website fitting

The current cover is restored to the repository's original **`img/poster.jpg`**, rather than either of the newly generated replacement covers.

The original is 1672 × 941. The website adapts it to a responsive **3:1** banner aligned to the content column. A deliberate centred crop preserves the project title, familiar-song statement, MusicTag and hand. The less important top commission line and excess lower background sit outside that web crop. The image itself is unchanged.

On desktop the banner follows the content column's left and right margins. On narrow screens it follows the page gutter. It is not stretched, and it no longer fills the full browser width regardless of the editorial layout.

The README references the original image. Earlier generated v2/v3 files remain available as history but are not used by the current portfolio or README.
